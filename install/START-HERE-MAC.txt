Your own second brain, started from the AnIdeaLab brain kit, on a Mac.

What you'll have at the end:
- Your brain: a private GitHub repo of plain notes. A core page every AI agent reads, 65 skills
  (how to do things) and a knowledge library that fills up as you use it.
- Obsidian on your Mac, showing your brain as a map, and the brain graph replaying how it grew.
- The Mac runner: it lets Claude run jobs on your Mac while it's on and you're logged in.

You need: a Mac, a Claude plan, and about 30 minutes, mostly waiting for installs.

1. OPEN TERMINAL: press Command and Space, type terminal, press Enter.

2. PASTE THIS LINE into the Terminal window and press Enter:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/AnIdeaLab/brain-kit/main/install.sh)"

   It installs Apple's command line tools (they have Git), GitHub's command line and Obsidian,
   if they're missing. It doesn't need your Mac's password. Its questions show in yellow.
   It asks you to:
   - accept AnIdeaLab's terms of use: type Y and press Enter. Read them first, here or by typing
     V in the setup: https://github.com/AnIdeaLab/brain-kit/blob/main/TERMS.md
   - if a window asks to install the command line developer tools: click Install, then Agree.
     It takes 5 to 20 minutes, and the setup carries on by itself once they're in;
   - sign in to GitHub in your browser, copying a code from the window (no account yet? make
     one on that page, it's free);
   - name your brain (press Enter for my-brain). Your brain's repo is private;
   - say yes to the Mac runner. macOS then says background items were added: that's the runner;
   - say yes to keeping the Mac awake while it's on the charger (jobs can't run while it sleeps);
   - last, Obsidian opens your brain: choose "Trust author and enable plugins", then come
     back to Terminal, which lists each step and what to do next.

   If it stops partway, paste the same line again: it skips what's already done. What it
   did is kept in ~/AI-Brain-Link/_logs/install.log.

3. CONNECT CLAUDE:
   - Go to https://claude.ai/code. If it asks, connect GitHub and let Claude see your brain repo.
   - Start a new session with your brain repo selected, and send:

       This is my new second brain. Read CLAUDE.md and get me set up.

   Claude asks you a few questions, tests the Mac runner and shows you around.

Later:
- Agents can run jobs on your Mac while it's on, awake and you're logged in. Closing the lid
  puts it to sleep, and so does running on battery.
- To give your brain files, put them in the _upload folder in AI-Brain-Link (in Finder: Go,
  Home, then AI-Brain-Link), and tell Claude what to do with them.
- Keys for services never go in a chat. Claude gives you one line to paste into Terminal,
  which opens the page that makes the key and saves it in your brain's GitHub secrets.
- To check your setup any time, paste this into Terminal. It changes nothing, and copies a
  report you can paste into Claude with "Fix what this setup check found":

bash ~/AI-Brain-Link/my-brain/skills/my-mac/check-setup.sh

  (Put your brain's name in place of my-brain if you named it something else.)
