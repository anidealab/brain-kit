# AnIdeaLab's set-up tools

For the second brain set up for you (AnIdeaLab's paid set-up), not part of a brain. A brain's own owner brings their files in with the brain's file-intake skill, choosing what goes in; this folder is what AnIdeaLab runs for a set-up buyer, so they don't have to pick out or send any files.

**Index my computer** finds the documents someone worked on in the last 12 months and turns them into text, for the agent doing the set-up to write up as notes in their brain with the file-intake skill (from its step 2). Since 25 Nov 2026 it goes in two stages, so it reads what matters to them and not a whole computer's worth (tried on two computers that day, the one-step read took in a backup drive's copies as 61% of the text):
1. **The map**, as the installer's last step. It's a setting of the kit's installer, off unless it's set: `BRAIN_KIT_SETUP=1` in front of the one command (`$env:BRAIN_KIT_SETUP='1'; irm ... | iex` on a PC, `BRAIN_KIT_SETUP=1 /bin/bash -c "$(curl ...)"` on a Mac), which is the command the set-up page gives. Nothing hides it: anyone can set it. With it, the installer also lets AnIdeaLab's set-up account in on a brain made from the template, and runs `index-computer -Map` (`--map` on a Mac) right there, as the owner: the folders and the past year's documents' names, nothing opened, in seconds (5 on a big PC). The work folder, zipped, goes on the brain's repo as a private draft release, `anidealab-set-up-index` (never in the brain's files).
2. **The plan.** The set-up's agent reads the map (`folders.md`, `map.md`) with the owner's answers and writes a plan: the folders and files to read, what to skip, and a time limit.
3. **The read**, a job on the owner's own runner: `index-computer -Plan <file> -Minutes 45` (`--plan`, `--minutes`), newest first; what the time leaves is read by `-More` later. The work folder comes back as the run's artifact, never into the brain's files. The agent writes the notes, and deletes the release and the artifact.

With no mode, the script maps and reads it all in one go, as it did before.
- **What's searched** (by the map, and by a read the plan leaves to the usual folders): Desktop, Documents, Downloads, every OneDrive folder, the other folders in the home folder and, on Windows, the other fixed drives' folders. Left out: the system's, apps', browsers' and the brain's own folders, backups (a folder or drive named like one) and copies of a brain, apps' caches, wallets' folders, folders named like passwords or keys, and cloud drives' folders (Dropbox, Google Drive, iCloud Drive: a later step).
- **What goes in:** documents only (PDF, Word, Excel, PowerPoint, email, plain text and notes) changed in the last 12 months, and each code project (a folder with `.git`) as one row saying where it is. Exact copies are found and left out.
- **What's only counted, never listed or read:** photos, video and audio, archives, code and apps' files; anything named like passwords or keys; and a document whose text turns out to hold them, or is mostly numbers (a data file saved as text), which is dropped after reading.
- **A map of the computer** comes from the same walk, `map.md`: each drive's space, the folders searched and the ones inside them two deep, with what's in each (documents, photos, video, code) and when it last changed, whatever its age, the programs' and games' folders, the code projects, and the cloud drives not searched. The set-up's agent puts it in the brain's note on that computer (`knowledge/systems/my-pc.md` or `my-mac.md`), so later jobs know where things are.
- **Nothing on the computer is changed, moved or copied.** It writes only its work folder, `_intake/computer` in the brain's folder on the computer (`C:\AI-Brain-Link`, `~/AI-Brain-Link`), which holds `index.md` (what was searched, what went in and what was left out), and `files.txt`, `survey.md` and `text/` as the file-intake skill's survey and convert make them. uv, the Python it brings and MarkItDown are put in a folder of their own and taken off again at the end.

The files:
- [index-computer.py](index-computer.py): the search and the text, with the brain's [intake.py](../brain/skills/file-intake/intake.py), which it downloads beside itself.
- [index-computer.ps1](index-computer.ps1) (Windows) and [index-computer.sh](index-computer.sh) (Mac): get the tools and run it. The installer runs them as files; each one's top says how to run it on its own, or as a runner job.
