# The rules table

A rule that limits what agents can do (a "never", an "only", an "asks first") is kept only once the owner has said so. Agents write rules as they go, and a guess written as a rule quietly fences in every agent after it. This table lists those rules, so it's clear which are the owner's and which are waiting to be checked.

- **Not listed here:** the core's gates and defaults, which are the owner's and have their own decision notes.
- **A rule lives where it does its job** (a skill step, a project's note), with "(confirmed: the rules table)" beside it once it's confirmed. This table lists it, with a link back.
- **A new rule** an agent writes goes in as "not checked yet", and the agent mentions it to the owner in the thread ([the brain spec](../../skills/brain-spec/SKILL.md)).
- **The monthly deep audit** finds rules like these that aren't listed, and rows still "not checked yet", and asks the owner about each: kept, the row says confirmed, with their words; cut, the rule is deleted from where it lives and from this table ([the deep audit](../../skills/brain-audit/deep-audit.md#2-rules-not-checked-with-the-owner)).
