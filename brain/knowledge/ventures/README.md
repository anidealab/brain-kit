# Ventures

Each project's note says what it is, its goal in the owner's words, where it stands, its code repo and its look. Where it stands is a few dated lines linking the project's tasks and notes, not a copy of them; the weekly tidy-up rewrites it each week the project moves. A project with code keeps it in its own repo ([how](../../skills/brain-spec/SKILL.md#a-project-with-code-gets-its-own-repo)). Its tasks, decisions and people are on their own shelves, tagged with its name. A new project starts as one note and becomes a folder with its own `README.md` once it has several.
