# Brain updates

AnIdeaLab, which makes the brain kit this brain was started from, sends updates to brains made from it: fixes, new rules and new parts, through a public repo. A check at the start of a session, once a day, says when a new one is waiting, and the weekly tidy-up checks too. Waiting updates go in together, bringing the brain to the kit as it is now: the owner hears a summary of them, and they're applied only if they say go ([how](../../../skills/brain-spec/SKILL.md#brain-updates)).

**On kit update:** none applied yet; this brain started from the kit made on {KIT_DATE}.

Each update leaves a report here: what went in, what clashed and what broke. The "Send brain update reports" workflow sends it to AnIdeaLab's inbox, so the kit gets better for everyone. It runs on GitHub's machines, not the PC.
