# Keys check log

What the "Check keys" workflow (`.github/workflows/check-keys.yml`) printed each run, newest first; it keeps the last 12. Only "does it answer": one free call per key, nothing about what a key may do ([keys and accounts](keys-and-accounts.md#keys) says more). The weekly tidy-up reads the newest run, so a dead key or a key with no row gets seen within a week.
